# CypheerShield

CypheerShield is an automated security reconnaissance and vulnerability assessment tool developed by Cypheeeeer7. Designed for penetration testers and cybersecurity professionals, it provides rapid security header auditing, targeted port scanning, and an integrated license-key authentication system.

## Installation and Usage

### On Kali Linux / Linux

1. Clone the repository:
git clone https://github.com/Cypheeeeer7/CypheerShield.git

2. Navigate to the project directory:
cd CypheerShield

3. Install required dependencies:
pip install requests

4. Execute the application:
python3 CypheerShield.py

---

## Key Features

* License Authorization System: Secures tool usage with built-in key verification.
* Security Header Auditor: Analyzes web applications for missing security headers (CSP, HSTS, X-Frame-Options).
* Port Reconnaissance: Performs fast TCP connection checks on standard open ports.
* Cross-Platform Support: Compatible with Kali Linux, Ubuntu, Debian, and Linux-based environments.
